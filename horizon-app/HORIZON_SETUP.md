# Horizon Hero Section — Setup Guide

This sub-directory is a **standalone Next.js 14 app** that hosts the `HorizonHeroSection` React component.
The parent repo (`rush1998/Portfolio`) is a plain HTML/CSS/JS site, so React infrastructure lives here separately.

---

## Why `/components/ui`?

shadcn/ui uses `/components/ui` as its **canonical drop-in directory**.
All components generated by the shadcn CLI land there, and path aliases (`@/components/ui/…`) are pre-wired in `tsconfig.json`.
If you ever run `npx shadcn@latest add button` it will write to that folder automatically.
Keeping third-party UI components alongside shadcn components in the same folder avoids import-path fragmentation.

## Quick start

```bash
# 1. Enter the app directory
cd horizon-app

# 2. Install dependencies
npm install

# 3. Install Three.js + GSAP (already in package.json, just explicit)
npm install three gsap
npm install -D @types/three

# 4. Run dev server
npm run dev
# → http://localhost:3000
```

## Setting up from scratch (if starting fresh)

### 1. Bootstrap with shadcn CLI

```bash
npx shadcn@latest init
```

Choose:
- **Framework**: Next.js
- **Style**: Default
- **Base color**: Slate
- **Global CSS**: `app/globals.css`
- **Tailwind config**: `tailwind.config.ts`
- **Import alias**: `@/*` → `./`

This scaffolds:
```
app/
  globals.css       ← CSS variables + Tailwind directives
components/
  ui/               ← shadcn components go here  ← horizon-hero-section.tsx too
lib/
  utils.ts          ← cn() helper
tailwind.config.ts
tsconfig.json
```

### 2. TypeScript (already included)

Next.js 14 ships with TypeScript by default when you pass `--typescript` (or answer yes during `create-next-app`).
The `tsconfig.json` in this repo has strict mode enabled and the `@/*` path alias wired up.

### 3. Tailwind CSS (already included)

shadcn init installs and configures Tailwind automatically.
If you need to add it manually:

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Then add to `app/globals.css`:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 4. Install component dependencies

```bash
npm install three gsap
npm install -D @types/three
```

## Key implementation notes

1. **`'use client'` directive** is required — Three.js and GSAP rely on browser APIs (`window`, `requestAnimationFrame`, `canvas`) unavailable during SSR.
2. **`three/examples/jsm` imports** use `.js` extensions in the TypeScript source to satisfy the ESM bundler; `@types/three` provides the typings.
3. **`splitTitle()`** was moved from a standalone function to a typed arrow function returning `JSX.Element[]`; `ref` forwarding to repeated section titles was removed (React disallows a single ref on multiple elements).
4. **Responsive behavior**: The canvas is `position: fixed` and fills the viewport. Scroll sections are stacked below the first viewport height (`margin-top: 100vh`). On mobile the title uses `clamp(4rem, 15vw, 14rem)` fluid sizing.
5. **Best placement in portfolio**: Replace or augment the existing `<section class="hero">` in `index.html` — or run this Next.js app as a separate page linked from the main site (e.g. `/horizon`).
